# Automotive Predictive Maintenance Dashboard

## 🚗 Overview
Developed an end-to-end Power BI dashboard analyzing machine failure parameters for automotive manufacturing equipment.

## 🛠️ Tools & Technologies Used
* **Tool:** Power BI Desktop
* **Data Source:** Kaggle Predictive Maintenance Dataset

## 🔑 Key Features
* Visualized failure counts and performance metrics across equipment units.
* Tracked critical threshold failures to improve operational maintenance scheduling.
